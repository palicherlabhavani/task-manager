# Team Task Manager

## Description
This is a simple Task Manager web application built using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Data is stored using browser localStorage

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open the live application URL
2. Enter a task in the input box
3. Click "Add Task"
4. Mark tasks as completed
